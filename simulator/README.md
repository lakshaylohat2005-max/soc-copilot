# SOC Copilot Synthetic Attack Log Simulator

The simulator ([`simulate.py`](simulate.py)) generates realistic synthetic telemetry across three primary enterprise log sources:

1. **SSH Auth Logs** (`/var/log/auth.log` format): Failed logins, dictionary attacks, accepted passwords, PAM session opening.
2. **Web Server Access Logs** (Nginx combined format): HTTP requests, status codes, query strings, user-agents, SQL injection payloads.
3. **Firewall Logs** (Perimeter KV format): Allowed and dropped connections, port scans, bytes transferred, source/destination IPs.

> [!NOTE]
> All logs, IP addresses, and user accounts generated by the simulator are 100% synthetic and safe for hackathon and demo environments.

---

## Supported Attack Scenarios

| Scenario | Description | Key Characteristics |
|---|---|---|
| `normal` | Routine enterprise background noise | Legitimate employee web browsing, admin VPN SSH sessions, standard DNS/HTTPS traffic |
| `ssh_bruteforce` | Distributed SSH password spraying | 45+ failed logins within 2 minutes targeting varied usernames from an external attacker IP |
| `sql_injection` | Web application SQLi exploitation | Query parameter payloads (`' OR 1=1 --`, `UNION SELECT`) targeting API and web endpoints |
| `port_scan` | Network reconnaissance | Rapid-fire probes across 100+ TCP ports recorded in firewall deny logs |
| `credential_stuffing_then_login` | Compromise after credential stuffing | Sequence of failed password attempts followed by an accepted login for user `admin` |
| `data_exfil` | High-volume data exfiltration | Internal compromised host sending multi-hundred megabyte payloads to external anomalous IP |
| `full_attack_chain` | End-to-end multi-stage attack | Port Scan -> SSH Brute Force -> Admin Compromise -> Data Exfiltration from the same attacker IP |

## CLI Options & Usage

```bash
python simulate.py [OPTIONS]
```

### Options
- `--scenario`: Attack scenario (`normal`, `ssh_bruteforce`, `sql_injection`, `port_scan`, `credential_stuffing_then_login`, `data_exfil`, `full_attack_chain`). Default: `full_attack_chain`.
- `--target`: Ingestion endpoint URL. Default: `http://localhost:8000/api/ingest`.
- `--speed`: Playback speed multiplier (e.g. `2.0` = 2x speed, `10.0` = 10x speed). Default: `1.0`.
- `--batch-size`: Number of logs posted per HTTP batch. Default: `5`.
- `--attacker-ip`: Explicit attacker IP (defaults to a random realistic external IP).
- `--dry-run`: Preview log generation in the terminal without sending HTTP requests.
- `--loop`: Loop continuously for standing demo sessions.

### Examples

**1. Live Hackathon Demo (Full Attack Chain):**
```bash
python simulate.py --scenario full_attack_chain --speed 1.0
```

**2. Rapid Testing (10x Speed):**
```bash
python simulate.py --scenario ssh_bruteforce --speed 10.0
```

**3. Preview without backend (Dry-Run):**
```bash
python simulate.py --scenario sql_injection --dry-run
```

**4. Continuous background traffic:**
```bash
python simulate.py --scenario normal --loop --speed 2.0
```
